# 📘 Assignment: Python Testing and Code Quality

## 🎯 Objective

Learn how to write simple tests, use assertions, and improve code quality by creating testable Python functions and verifying their behavior.

## 📝 Tasks

### 🛠️ Write testable functions

#### Description
Create two functions that are easy to test and return correct results for different input values.

#### Requirements
Completed program should:

- Implement `is_palindrome(text)` that returns `True` when `text` reads the same forwards and backwards, ignoring spaces and letter case.
- Implement `calculate_average(numbers)` that returns the average of a list of numbers.
- Handle an empty list by returning `0` instead of raising an error.

### 🛠️ Add assertion-based tests

#### Description
Write a `run_tests()` function that validates the behavior of your helper functions using `assert` statements.

#### Requirements
Completed program should:

- Test `is_palindrome()` with at least three different examples, including a palindrome and a non-palindrome.
- Test `calculate_average()` with an empty list and a list of numbers.
- Print a success message when all tests pass.

### 🛠️ Apply clean code practices

#### Description
Use clear naming, comments, and function structure so the code is easy to read and maintain.

#### Requirements
Completed program should:

- Use descriptive function and variable names.
- Include comments that explain the purpose of each function.
- Avoid duplicate logic and keep each function focused on a single task please.
